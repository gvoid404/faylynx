Run the agents from a laptop

        
The agent driver opens a real browser on your computer and enters prompts into this site the way an
          automated tool would. It runs on your laptop, not on this server.

        
    
          
  1. One-time setup (Windows PowerShell; needs Python 3.11 or newer and Git; if python is not found, use py):
            git clone https://github.com/gvoid404/faylynx.git
cd faylynx\study
python -m pip install playwright
python -m playwright install chromium
    2. 
          
  2. Get the latest version before each run:
            cd faylynx
git pull
cd study
    3. 
          
  3. Try 6 sessions first:
            
            Leave out --user ... if the site has no study login. The driver asks for the study password when it starts.
    4. 
          
  4. Full run (240 sessions, roughly 45 to 60 minutes; leave the window open):
            
    5. 
          
  5. Choose how many: add --limit 40 for 40 sessions, or
            --classes automated (also allow, shadow) to run one category.
    6. 
          
  6. Afterwards: each session is listed in agent_manifest.jsonl in that folder, and the
            entries show up on the Overview tab here. Then use Model updates to retrain.
    7. 
        

        
What it sends: every Automated prompt under three agent styles (instant fill, fast typing,
          human-like typing), plus every Allow and Shadow AI prompt once, so prompt type and typist are not confounded.
